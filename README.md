# Doom Builder 64 II Enhanced
While Styd is busy incrementally updating Doom Builder 64 II until it reaches Ultimate Doom Builder features commit by commit, this fork adds cherry picks some of the the more modern features early. This serves as an early preview of the Doom Builder 64 II features while making it convenient for current mappers.

## Coding
This requires Microsoft Visual Studio to compile. Claude AI has been used to narrow down bugs and to compare different code bases.
